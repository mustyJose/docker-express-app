# Dockerized Express + MongoDB CRUD API

A backend REST API built with Node.js, Express.js, MongoDB, and Mongoose. The application is containerized using Docker and Docker Compose.

##  Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- Docker
- Docker Compose
- dotenv
